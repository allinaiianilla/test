第 20 章：TypeScript——安装 TypeScript 并运行 TypeScript 编译器 tsc

如何从命令行安装 TypeScript 并对 .ts 文件运行 TypeScript 编译器。

第 20.1 节：步骤

安装 TypeScript 并运行 TypeScript 编译器。

安装 TypeScript 编译器：

```
npm install -g typescript
```

检查 TypeScript 版本：

```
tsc -v
```

下载适用于 Linux/Windows 的 Visual Studio Code：
Visual Code 下载链接

打开 Visual Studio Code：
1. 打开安装 TypeScript 编译器的同一文件夹
2. 点击左侧面板上的加号图标添加文件
3. 创建一个基础类。
4. 编译你的 TypeScript 文件并生成输出。
5. 查看编译后的 JavaScript 代码结果。
