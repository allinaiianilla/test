📄 Part 1: HTML — 网页骨架

HTML 用标签描述内容。最重要的概念：块级元素（占整行）vs 行内元素（排在同一行）。

🔧 最常用的 12 个标签

标签类型用途
<div>块万能容器，布局全靠它
<span>行内文本中的小片段标记
<p>块段落
<a href="...">行内超链接
<img src="...">行内块图片
<input>行内块输入框/按钮/复选框
<button>行内块按钮
<ul> + <li>块无序列表
<table>块表格
<form>块表单容器
<h1>~<h6>块标题
<strong> / <em>行内加粗/斜体

📐 HTML 页面骨架（每个网页都是这样）

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页面标题</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- 所有可见内容写在这里 -->
  <script src="app.js"></script>
</body>
</html>
💡 关键认知：HTML 描述"有什么"，CSS 描述"长什么样"，JS 描述"怎么动"。三者分工明确，不要混。

📐 Flexbox — 现代布局必学（80% 的布局用它搞定）

/* 父容器 */
.container {
  display: flex;
  justify-content: space-between;  /* 水平：两端对齐 */
  align-items: center;            /* 垂直：居中 */
  gap: 16px;                       /* 子元素间距 */
  flex-wrap: wrap;                 /* 超出换行 */
}

🛠️ 完整实战：一个计数器应用

HTML 结构 → CSS 样式 → JS 逻辑，三者的完整配合。

计数：0

<!-- HTML -->
<p>计数：<strong id="counter">0</strong></p>
<button onclick="change(-1)">-1</button>
<button onclick="reset()">重置</button>
<button onclick="change(1)">+1</button>

// JavaScript
let count = 0;
const update = () => {
  document.querySelector("#counter").textContent = count;
};
const change = (n) => { count += n; update(); };
const reset = () => { count = 0; update(); };
