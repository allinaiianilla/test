📄 阶段一：HTML 骨架 (Day 1-8)

Day 1：搭建第一个网页 HTML

🍎 基础题

  1. 在桌面新建一个 .html 文件，写入 <!DOCTYPE html>、<html>、<head>、<body> 骨架，用浏览器打开
  2. 在 <title> 里设置网页标题为"我的第一个网页"
  3. 在 <body> 里写一行 <h1>Hello World</h1>

🔥 进阶题

  1. 再加一个 <p> 段落，写一句介绍自己的话
  2. 在段落里用 <br> 换行
Day 2：文本标签 HTML

🍎 基础题

  1. 写出 h1 到 h6 六个标题，观察字体大小差异
  2. 写一段话，用 <strong> 加粗关键词，用 <em> 斜体关键词
  3. 写一个无序列表 <ul>，列出你的三个爱好

🔥 进阶题

  1. 写一个有序列表 <ol>，列出做菜的步骤（3步）
  2. 嵌套列表：一个大分类下有小分类
Day 3：链接与图片 HTML

🍎 基础题

  1. 用 <a href="..."> 创建跳转到百度的超链接
  2. 用 <a href="..." target="_blank"> 创建新窗口打开的超链接
  3. 用 <img src="..."> 插入一张网络图片

🔥 进阶题

  1. 制作一个导航栏：用链接写出"首页 | 关于 | 联系"
  2. 给图片加 alt 属性，图片加载失败时显示替代文字
Day 4：div 与 span HTML

🍎 基础题

  1. 用 <div> 包裹一个标题和一个段落，观察块级特性
  2. 在一段文字中用 <span> 包裹几个字
  3. 写 3 个 <div> 并排放置（先不管样式，观察默认行为）

🔥 进阶题

  1. 给 div 加上 style="background:#eee; padding:10px; margin:5px" 观察效果
  2. 理解块级 vs 行内：div 会换行，span 不换行
Day 5：表格 HTML

🍎 基础题

  1. 创建一个 3 行 3 列的表格（<table>/<tr>/<td>）
  2. 给表格加表头 <th>
  3. 用 border="1" 给表格加边框

🔥 进阶题

  1. 做一张课程表（星期/课程名/时间）
  2. 用 colspan 合并两个单元格
Day 6：表单基础 HTML

🍎 基础题

  1. 用 <form> 包裹创建一个文本输入框 <input type="text">
  2. 创建一个密码输入框 <input type="password">
  3. 创建一个提交按钮 <button type="submit">

🔥 进阶题

  1. 创建一个登录表单（用户+密码+登录按钮）
  2. 加一个复选框 <input type="checkbox"> "记住我"
Day 7：多媒体与语义标签 HTML

🍎 基础题

  1. 用 <audio controls> 嵌入一个音频文件链接
  2. 用 <video controls> 嵌入一个视频
  3. 用 <iframe> 嵌入一个B站视频

🔥 进阶题

  1. 了解语义化标签：<header>/<main>/<footer>/<nav>/<article>
  2. 用这些语义标签重新组织一个新闻页面
Day 8：HTML 综合挑战 HTML

🍎 基础题

  1. 做一张个人名片：头像图片 + 姓名(h2) + 简介(p) + 联系方式列表
  2. 加入导航链接：GitHub / 博客 / 邮箱

🔥 进阶题

  1. 做一份 HTML 简历：个人信息、教育经历(table)、技能列表(ul)、项目经验
  2. 所有标签语义化，不使用 div 堆砌

🎨 阶段二：CSS 样式 (Day 9-18)

Day 9：CSS 入门 CSS

🍎 基础题

  1. 用三种方式写 CSS 给 h1 变红色：内联 style / <style> 标签 / 外部 .css 文件
  2. 用类选择器 .box { } 给 div 加背景色
  3. 用 ID 选择器 #main { } 给元素加边框

🔥 进阶题

  1. 写一个子代选择器 .card > h2，只选中直接子元素
  2. 写一个悬停效果 button:hover 改变背景色
Day 10：盒模型 CSS

🍎 基础题

  1. 创建一个 div，分别设置 width、height、padding、border、margin
  2. 用 Chrome 开发者工具（F12）查看盒模型
  3. 理解 box-sizing: border-box 的含义并应用

🔥 进阶题

  1. 创建 3 个并排的卡片，用 margin 控制间距
  2. 用 padding 让卡片内的文字不贴边
Day 11：颜色、字体、背景 CSS

🍎 基础题

  1. 用 color/background-color 给文字和背景上色（用 #hex、rgb()、直接颜色名三种方式）
  2. 设置 font-size 和 font-weight，观察效果
  3. 用 text-align: center 居中对齐文字

🔥 进阶题

  1. 用 background-image 设置全屏背景图
  2. 用 font-family 设置中英文混排字体栈
Day 12：阴影、圆角、渐变 CSS

🍎 基础题

  1. 给卡片加 box-shadow（提升质感的关键）
  2. 用 border-radius 做圆角卡片（>10px）
  3. 用 border-radius: 50% 做圆形头像

🔥 进阶题

  1. 写一个 linear-gradient 渐变背景按钮
  2. 给文字加 text-shadow 阴影效果
Day 13：Flexbox 上 CSS

🍎 基础题

  1. 创建一个 flex 容器，放 3 个子 div
  2. 用 justify-content: center / space-between / space-around 三种对齐
  3. 用 align-items: center 垂直居中

🔥 进阶题

  1. 做一个导航栏：logo 在左，菜单在右（justify-content: space-between）
  2. 用 flex-wrap: wrap 做自适应卡片布局
Day 14：Flexbox 下 CSS

🍎 基础题

  1. 用 flex-direction: column 做垂直排列
  2. 用 flex: 1 让子元素等分剩余空间
  3. 用 gap 控制子元素间距（比 margin 更优雅）

🔥 进阶题

  1. 做一个圣杯布局（header / 三列内容 / footer）
  2. 做一个居中对齐的登录框（水平+垂直都居中）
Day 15：Grid 上 CSS

🍎 基础题

  1. 创建一个 Grid 容器，grid-template-columns: repeat(3, 1fr)
  2. 用 grid-template-rows 设置行高
  3. 用 gap 设置网格间距

🔥 进阶题

  1. 做一个 3×3 的图片画廊
  2. 用 grid-column: span 2 让某个元素跨两列
Day 16：响应式设计 CSS

🍎 基础题

  1. 用 @media (max-width: 768px) { } 写移动端样式
  2. 设置 viewport meta 标签
  3. 用相对单位 rem / % / vw 代替 px

🔥 进阶题

  1. 做一个两栏布局：桌面端并排，手机端上下堆叠
  2. 用 clamp() 函数做自适应字号
Day 17：过渡与动画 CSS

🍎 基础题

  1. 给按钮加 transition: background 0.3s，hover 时变色
  2. 用 transform: scale(1.05) 做悬停放大效果
  3. 写一个简单的 @keyframes 淡入动画

🔥 进阶题

  1. 做一个 loading 旋转动画（@keyframes spin）
  2. 给卡片加 hover 上浮效果（translateY + shadow）
Day 18：CSS 综合挑战 CSS

🍎 基础题

  1. 把 Day 8 的个人名片用 CSS 美化（加阴影/圆角/渐变/间距）
  2. 用 Flexbox/Grid 重新布局名片

🔥 进阶题

  1. 做一个产品展示卡片（图片+标题+价格+购买按钮），Hover 有动效
  2. 整套卡片在桌面端 3 列、平板 2 列、手机 1 列
