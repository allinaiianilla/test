01HTML — 网页的骨架

HTML（超文本标记语言）用标签描述页面里"有什么"：一个标题、一段文字、一张图片、一个按钮。

最小完整页面

常用标签速查

标签用途示例

<p>段落<p>一段文字</p>
<a>链接<a href="网址">点我</a>
<img>图片（自闭合）<img src="a.png">
<div>通用块容器<div>…</div>
<span>行内容器<span>…</span>
<ul><li>无序列表<ul><li>项</li></ul>
<button>按钮<button>提交</button>
<input>输入框<input type="text">
💡 记忆法：HTML 只管内容，不管长相。"这里是个标题"是 HTML 的事，"标题是红色 32px"是 CSS 的事。

02CSS — 网页的皮肤

CSS（层叠样式表）控制页面的"长相"：颜色、大小、间距、布局、动画。核心语法就一条公式：

选择器 { 属性: 值; } —— 选中谁，改什么，改成啥。

选择器与基础样式

selector.html

盒模型：一切布局的基础

每个元素都是一个盒子：content（内容）→ padding（内边距）→ border（边框）→ margin（外边距），从里到外一层套一层。

box.html — 改数字看变化

Flexbox：现代布局神器

一行代码让子元素横向排列、居中、平分空间。90% 的布局用它就够。

flex.html
💡 常用属性背这五个就够了：color 文字色 / background 背景 / font-size 字号 / padding 内距 / margin 外距。布局交给 flex。

03JavaScript — 网页的大脑

JS 让页面"活"起来：响应点击、修改内容、请求数据。它是真正的编程语言，有变量、函数、逻辑。

变量、函数、事件：三样撑起 80% 的场景

04三者如何协作

一个网页 = 房子：HTML 是毛坯结构，CSS 是装修，JS 是水电和智能设备。分工明确，各改各的，互不干扰。

管什么文件一句话
HTML结构与内容.html页面上有什么
CSS外观与布局.css长什么样
JS行为与交互.js能做什么

实际项目里三者分三个文件，用两行代码关联：

<link rel="stylesheet" href="style.css">（放 head 里）
<script src="app.js"></script>（放 body 最底部）

05下一步学什么

  1. 动手改这个文档 —— 每个示例都改一遍参数，看效果变化，比看十遍都有用
  2. 做一个个人主页 —— 综合运用三件套的最小实战
  3. 学 Chrome DevTools —— F12 打开，随时偷看任何网站的代码
  4. MDN Web Docs —— 前端界的官方字典：developer.mozilla.org
  5. 之后再进阶：Fetch/API 请求 → ES6+ 语法 → Vue / React 框架
