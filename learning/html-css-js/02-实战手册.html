项目Ⅰ · 个人名片页 入门

目标：一个居中、带头像、有社交按钮的卡片页面。学会 HTML 搭结构 → CSS 排版 → hover 交互。

1先写骨架：只管内容，不看好坏
step1 — 裸结构
现在很丑，正常。先保证内容对、层级清，再动手美化——这是专业前端的工作顺序。
2加 CSS：居中卡片 + 圆头像
step2 — 有了设计感
3加交互：hover 悬停效果 + 按钮化链接
step3 — 最终成品（改文字换成你自己的）
挑战：把头像换成你自己的图片链接，把 linear-gradient(135deg,#0f172a,#1e293b) 改成你喜欢的两个颜色，体验"改两个值→整体换风格"。

项目Ⅱ · 互动问答卡片 进阶

目标：一道选择判断题，点选项立即判对错、计分、下一题。学会 JS 数据驱动界面——先有数据，再渲染，事件只改数据。

1思路：题目是数据，界面是数据的影子

不要想着"点按钮改页面"，而要想："点按钮改数据（第几题/得分），数据变了重新画一遍界面"。这是现代前端的核心理念，Vue/React 都是这个思想的框架化。

2完整实现（60 行，建议逐段读懂再运行）
quiz.html — 数据驱动 UI
关键洞察：render() 是唯一碰界面的函数，事件函数只改 idx / score。以后学 Vue，会发现它就是把 render 自动化了。
挑战：加两道自己的题；把答错扣分做成双倍计分；给进度条加个 <progress> 标签。

项目Ⅲ · 记账小应用 综合

目标：输入金额和备注，记录收支、自动算总额、刷新页面数据不丢。学会 localStorage 持久化 + 列表渲染 + 汇总计算——这就是一个真正的应用。

bills.html — 关掉再打开，数据还在
三个新知识点：
① localStorage：浏览器自带的键值数据库，setItem / getItem，存的是字符串所以要 JSON.stringify / parse
② reduce：把数组折叠成一个值，算余额一行搞定
③ e.preventDefault()：阻止表单默认行为（否则页面会刷新，数据状态全丢）
毕业挑战：① 按日期分组显示 ② 加一个"清空全部"按钮（记得二次确认）③ 把每笔记录加上时间显示。做完这三个，你就超过大部分初学者了。
